# Кейс-задача №4 — WEB-приложение «Система учета заявок клиентов»

## Цель работы

Провести анализ информационных систем, построенных по архитектуре WEB-приложений, рассмотреть их основные возможности и варианты использования в компании.

Разработать прототип WEB-приложения с использованием Delphi 10.2 и Microsoft Internet Information Services (IIS). Для хранения информации используется база данных Microsoft SQL Server.

## Анализ информационных систем WEB-архитектуры

WEB-приложения широко применяются в современных организациях, поскольку позволяют пользователям работать с информационной системой через браузер. Основная обработка данных выполняется на серверной стороне, а пользователю предоставляется WEB-интерфейс.

К распространенным видам информационных WEB-систем относятся:

### CRM-системы

CRM-системы предназначены для управления взаимоотношениями с клиентами.

Основные возможности:

* хранение информации о клиентах;
* регистрация обращений;
* управление сделками;
* контроль работы менеджеров;
* формирование отчетов.

В компании CRM-система может использоваться отделом продаж и службой поддержки клиентов.

### ERP-системы

ERP-системы используются для комплексного управления ресурсами организации.

Основные возможности:

* управление финансами;
* учет товаров;
* управление закупками;
* управление персоналом;
* формирование аналитической отчетности.

Такие системы могут применяться для объединения различных бизнес-процессов компании в единой информационной среде.

### Help Desk / Service Desk

Системы данного типа предназначены для регистрации и обработки обращений пользователей.

Основные возможности:

* создание заявок;
* назначение ответственного сотрудника;
* изменение статуса заявки;
* хранение истории обращений;
* контроль сроков выполнения.

Подобные системы могут использоваться службой технической поддержки или другими подразделениями компании, работающими с обращениями сотрудников и клиентов.

### CMS

Системы управления контентом позволяют управлять содержимым WEB-сайта через браузер.

Основные возможности:

* создание страниц;
* публикация материалов;
* редактирование информации;
* управление пользователями;
* разграничение прав доступа.

CMS может применяться для корпоративного сайта, информационного портала или внутреннего ресурса организации.

## Преимущества WEB-архитектуры

Использование WEB-архитектуры имеет ряд преимуществ:

* доступ к системе через WEB-браузер;
* централизованное хранение информации;
* возможность одновременной работы нескольких пользователей;
* упрощение обновления серверной части приложения;
* возможность использования системы в локальной корпоративной сети;
* возможность организации удаленного доступа;
* разделение пользовательского интерфейса, серверной логики и базы данных.

## Разработанное приложение

В рамках кейс-задачи разработан учебный прототип WEB-приложения **«Система учета заявок клиентов»**.

Приложение предназначено для регистрации обращений клиентов компании.

WEB-интерфейс содержит форму со следующими данными:

* имя клиента;
* адрес электронной почты;
* текст заявки.

Для WEB-части используется Delphi WebBroker.

В качестве WEB-сервера предусмотрено использование Microsoft Internet Information Services (IIS).

Для хранения информации разработана база данных Microsoft SQL Server.

## Архитектура приложения

Приложение построено по следующей схеме:

`WEB-браузер → IIS → Delphi WebBroker → MS SQL Server`

### WEB-браузер

Предоставляет пользовательский интерфейс для работы с системой.

### Microsoft IIS

Используется в качестве WEB-сервера и обеспечивает обработку входящих HTTP-запросов и взаимодействие с серверным приложением.

### Delphi 10.2 / WebBroker

Реализует серверную часть WEB-приложения и формирование HTML-ответов.

### Microsoft SQL Server

Предназначен для централизованного хранения данных приложения.

## База данных

Для приложения разработана база данных:

`WebRequests`

Основная таблица:

`Requests`

Структура таблицы:

* `Id` — уникальный идентификатор заявки;
* `ClientName` — имя клиента;
* `Email` — электронная почта;
* `RequestText` — текст обращения;
* `CreatedAt` — дата и время создания заявки.

Поле `Id` является первичным ключом.

SQL-скрипт создания базы данных и тестовых записей находится в файле:

`database.sql`

## Структура проекта

Репозиторий содержит следующие основные файлы:

* `WebRequests.dpr` / `WebRequests.dpr` — главный файл проекта Delphi;
* `WebModuleUnit1.pas` — программная логика WEB-модуля;
* `WebModuleUnit1.dfm` — описание WEB-модуля;
* `database.sql` — скрипт создания базы данных MS SQL Server;
* `README.md` — описание проекта и проведенного анализа.

## Возможности использования в компании

Разработанное приложение может быть использовано как основа системы регистрации обращений клиентов.

Например, сотрудник или клиент компании может создать заявку через WEB-интерфейс. Информация о заявке может быть сохранена в централизованной базе данных, после чего сотрудники компании смогут использовать ее для дальнейшей обработки обращения.

Подобная архитектура может применяться для:

* регистрации обращений клиентов;
* внутренних заявок сотрудников;
* заявок на обслуживание;
* учета запросов пользователей.
